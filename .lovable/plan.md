# Полноценная админ-панель магазина

Цель: в разделе «Панель управления» полностью управлять ассортиментом (включая загрузку фото с компьютера) и видеть заказы со статусами.

## Фото товаров — загрузка с компьютера

- Создаётся публичное хранилище для фото товаров (лимит 10 МБ на файл, только изображения).
- В карточке товара: кнопка «Загрузить фото» + перетаскивание файлов, можно выбрать сразу несколько.
- Загруженные фото показываются миниатюрами: можно менять порядок (первое = главное на карточке), удалять по одной, при желании добавить фото по ссылке.
- Фото сохраняются сразу при загрузке, полностью заменяя ручной ввод ссылок (поле со ссылками остаётся как дополнительная возможность).

## Товары — редактирование всех данных

- Форма товара переезжает в удобное окно на весь экран (нормально листается на любом размере экрана): название, адрес страницы, подзаголовок, описание, состав, уход, цена, старая цена, категория, теги, остаток, публикация, витрина на главной.
- Кнопка «Дублировать товар» — быстрое создание похожей позиции.
- Автоматическое создание адреса страницы из названия (транслитерация), с возможностью правки.
- Список товаров: поиск по названию, фильтр по категории и по «скрытые/опубликованные», сортировка по дате/цене/названию.
- Быстрые действия прямо в списке: показать/скрыть, добавить/убрать из витрины, изменить остаток.

## Заказы

- Сводка сверху: количество новых заказов, в работе, выполненных, сумма за сегодня и за месяц.
- Фильтр по статусу и поиск по номеру заказа, имени, телефону.
- Карточка заказа: покупатель, контакты, доставка, дата, комментарий, товары с фото, суммы.
- Статус меняется одним нажатием: новый → подтверждён → отправлен → выполнен → отменён; видна дата последнего изменения.

## Категории

Остаётся создание, переименование, удаление и порядок; добавляется показ количества товаров и предупреждение при удалении непустой категории.

## Технические детали

- Storage bucket `product-images` (public), RLS-политики на `storage.objects`: чтение всем, запись/удаление — только роль `admin` через `has_role`.
- Загрузка из браузера через клиент Supabase в путь `products/<uuid>.<ext>`; в `products.images` пишется публичный URL.
- Расширение `src/lib/admin.functions.ts`: пакетное обновление флагов/остатка, дублирование товара, удаление файла из хранилища; статистика заказов считается на сервере одним запросом.
- Формы товара/категории — в `Dialog` из shadcn с внутренним скроллом; фильтры и поиск на клиенте по уже загруженным данным.
- Никаких изменений в публичной части магазина, кроме того, что новые фото подхватываются автоматически.
