# Moscow Bloom Boutique

Create an eco-friendly products store in Moscow with a light, spring, romantic aesthetic (botanical accents, soft pastel palettes, fluid organic cards, non-standard editorial e-commerce layout). Include a header, hero/main showcase, product catalog with filters, detailed product modal/page, shopping cart with checkout, Moscow delivery terms, privacy policy and public offer pages, footer, and an admin panel to manage products and incoming orders.
