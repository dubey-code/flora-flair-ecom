# Чат-бот консультант в правом нижнем углу

Кнопка чата на всех страницах магазина. Посетитель оставляет имя и телефон, соглашается с политикой конфиденциальности и общается с ИИ-консультантом, который знает ассортимент, помогает подобрать товары, считает сумму и оформляет заказ. При затруднении подключается живой оператор из админки. Все чаты видны в админке.

## Что увидит посетитель

- Круглая кнопка с иконкой чата в правом нижнем углу (пастельная, в стиле магазина), с точкой-индикатором нового ответа.
- Первый экран: имя, телефон, галочка «Согласен с политикой конфиденциальности» (ссылка на страницу). Без согласия кнопка неактивна.
- Затем — окно чата: приветствие консультанта, ответы печатаются по мере генерации, видно, когда он «думает».
- Консультант рекомендует конкретные товары: карточка с фото, названием, ценой и кнопкой «Добавить в заявку». Он ведёт список подбора и показывает сумму с учётом доставки по Москве.
- Кнопки «Оформить заказ» (спрашивает способ доставки, адрес/дату, затем создаёт настоящий заказ и сообщает номер) и «Позвать оператора».
- Разговор сохраняется в этом браузере: после перезагрузки чат открывается с историей.
- Когда оператор отвечает из админки, сообщение появляется в чате посетителя (проверка новых сообщений каждые несколько секунд), ИИ при этом молчит.

## Что увидит администратор

Новая вкладка «Чаты» в админ-панели:

- Список разговоров: имя, телефон, время последнего сообщения, статус (ИИ / нужен оператор / отвечает оператор / закрыт), метка «есть заявка».
- Сводка сверху: всего чатов, новых обращений к оператору, чатов за сегодня.
- Открытый чат: вся переписка (включая сообщения ИИ), поле ответа оператора, кнопки «Взять в работу» (ИИ отключается), «Вернуть ИИ», «Закрыть».
- Тикеты: обращения к оператору выделены и фильтруются отдельно; из чата видна ссылка на созданный заказ.

## Технические детали

**База данных (одна миграция):**
- `chat_sessions`: `visitor_name`, `phone`, `consent_at`, `token` (секрет посетителя, uuid), `status` (`bot` | `needs_operator` | `operator` | `closed`), `order_id`, `last_message_at`, таймстемпы.
- `chat_messages`: `session_id`, `role` (`user` | `assistant` | `operator` | `system`), `content`, `products` (jsonb — рекомендованные позиции), `created_at`.
- GRANT: только `authenticated` (чтение/запись админом через RLS `has_role(auth.uid(),'admin')`) и `service_role`. Никакого доступа для `anon` — посетитель работает исключительно через серверные функции, авторизуясь своим `token`.

**Серверные функции (`src/lib/chat.functions.ts`, без авторизации, доступ по токену сессии):**
- `startChatSession` — валидация имени/телефона/согласия (zod), создание сессии, возврат `{ sessionId, token }`.
- `getChatState` — по `sessionId` + `token` возвращает сообщения и статус (используется для подхватывания ответов оператора).
- `sendChatMessage` — записывает сообщение посетителя; если статус `bot`, вызывает Lovable AI и записывает ответ.
- `requestOperator` — ставит статус `needs_operator`, добавляет системное сообщение.
- `createChatOrder` — валидирует позиции и данные доставки, вызывает существующую RPC `create_order`, привязывает `order_id` к сессии, возвращает номер и сумму.

Все записи в таблицы — через `supabaseAdmin`, загружаемый внутри обработчика, после проверки токена.

**ИИ:** Lovable AI Gateway, модель `openai/gpt-6-astra` через Responses API со стримингом. Системный промпт на русском: роль консультанта «Московской весны», правила доставки из `src/lib/format.ts`, запрет выдумывать товары. Каталог доступен инструментами: `search_products` (поиск по опубликованным товарам с ценами/остатком), `get_product` (детали), `quote_cart` (расчёт суммы и доставки), `request_operator`. Стриминг идёт через серверный роут `src/routes/api/chat.ts`; сохранение сообщений — в `onFinish`. Ошибки шлюза (нет кредитов, лимит) показываются в чате понятным текстом.

**Админ-функции (`src/lib/admin.functions.ts`):** `adminListChats`, `adminGetChat`, `adminSendOperatorMessage`, `adminSetChatStatus` — все через `requireSupabaseAuth` + проверку роли `admin`.

**Клиент:** `src/components/chat/chat-widget.tsx` (кнопка + панель), `chat-lead-form.tsx`, `chat-message.tsx`, `chat-product-card.tsx`. Виджет монтируется в `src/components/site-shell.tsx`, чтобы был на всех страницах магазина, но не в админке. `sessionId`/`token` хранятся в localStorage, чтение — после гидрации. Новая вкладка «Чаты» добавляется в `src/routes/admin.tsx`.
